An explicit `nil` argument for an optional JSON body now sends JSON `null` when
the schema permits it. Omit the argument to send no body. Multipart inputs use
part records containing `value` and optional metadata, as documented in
`docs/media-contracts.md`.

Environment configuration retains `base_url` only when explicitly configured.
An absent value lets each operation use its declared server. Read the resolved
client URL from `new_client`, rather than the environment projection.
